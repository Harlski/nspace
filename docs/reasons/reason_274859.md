# reason_274859 — In-room mini-games vs isolated Matches

**Why:** Mosquito Tag is the first mini-game whose sport is the shared social room (chase among Bystanders), not a private pitch. Without a durable split, it is too easy to reuse soccer **Challenge** / **Match Pitch** / `WORLDCUP_ENABLED` because that is the only Games Wheel path today.

**How it serves the larger system:** Isolation stays reserved for sports that need a private pitch, ball, or stands. In-room games keep Hub/Commons movement (click-to-walk Path Playback) and do not smuggle pitch free-move into obstacle rooms. Keeping Mosquito Tag out of the seasonal World Cup module means Soccer can still be flagged off and deleted without taking the next game with it. The Games Wheel becomes a list of games, not a World Cup synonym.
