# Reason 418276

**Date:** 2026-11-22

**Why `THE-LARGER-SYSTEM` changed:** Wallet players could enter the world, including the Nimiq Pay tutorial, without a custom username. The login picker allowed skips, and the hourly digest then showed a shortened address with the Nimiq Pay mark stuck to it. Operators could not tell a chosen name from a wallet fragment.

**How this serves the larger system:** A shared social space needs a stable name before a wallet is present. Requiring that name at the next login, and refusing the game socket until it exists, keeps the rule on the server rather than only in the client modal. The digest prints that name on its own, with New and Nimiq Pay in separate columns, so the table stays readable as more players arrive. Guests and username-set bans stay exceptions, because neither can choose a wallet username.
