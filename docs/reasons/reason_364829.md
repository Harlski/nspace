# Why THE-LARGER-SYSTEM was updated (364829)

**What changed:** Recorded that Nimiq Pay Payment Intent sends must attach the intent memo as hex `data` / `recipientData` and UTF-8 `extraData` on the first `sendBasicTransactionWithData` call.

**Why:** Verify matches on-chain recipient data to the memo. Hub already uses `extraData`. Pay was sending plaintext `data` first; hosts that treat `data` as RPC hex (or read Hub `extraData`) dropped the message, the tx still confirmed, and hex retry never ran. Refusing an empty memo in JS was not enough.

**How it serves the larger system:** Incoming NIM (advertise, Unlock Pad, cosmetics) stays auto-verifiable when paid inside Nimiq Pay, instead of landing as unmatchable transfers that need admin credit.
