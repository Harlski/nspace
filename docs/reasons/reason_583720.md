# reason_583720 — Admin-only WS side channels in THE-LARGER-SYSTEM

## Why update THE-LARGER-SYSTEM

Movement Watch needed a durable cross-cutting rule: operator path/click overlays must not ride
the regular room WebSocket stream (`state` / optional public `moveOrder`). Recording that
pattern keeps future admin debug features from “just enabling” room-wide path broadcasts.

## How it serves the larger system

Separating **player sync** from **admin opt-in side channels** protects player bandwidth and
privacy expectations while still letting operators debug pathfinding and visually watch for
bot-like click patterns. ADR 0013 and this recorded decision give implementers one place to
look before adding the next ops overlay.
