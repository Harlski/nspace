# Why THE-LARGER-SYSTEM was updated (847615)

**What changed:** Added the **Login-gated HTML pages name the missing session** principle and the **Campaign creatives are hosted uploads** recorded decision (ADR 0023).

**Why:** `/advertise` (and similar `/*` surfaces) treated a missing session as “Could not load campaigns,” which hides the real blocker. Campaign image paste-URL also left in-world billboards dependent on third-party hosts and skipped upload validation. Both are cross-cutting product rules, not one-off UI tweaks.

**How it serves the larger system:** Callers of login-gated pages get an honest Sign-in Gate instead of a fake load failure, and advertise Campaign pixels stay on hosts we control so format checks and admin replacement stay one path.
