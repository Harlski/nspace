# Reason 123497 — Vercel / Docker must build `@nspace/i18n` before client/server

## Why THE-LARGER-SYSTEM changed

The Split SPA hosting note still said Vercel runs only `npm run build -w client`. After adding workspace package `@nspace/i18n` (exports point at gitignored `dist/`), that command fails on a clean install: Vite cannot resolve the package entry. The recorded build command must match production.

## How this serves the larger system

Deploy topology docs stay aligned with what actually builds on Vercel and in Docker, so agents and humans do not reintroduce a client-only build that drops shared Message Catalogs. Building i18n first (and shipping `packages/i18n` in the game image) keeps Locale Preference / `t()` available on both the static SPA and the API server without committing `dist/` to git.
