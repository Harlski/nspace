# Why THE-LARGER-SYSTEM was updated (482736)

**What changed:** Recorded that Space operators map Live Event types to interactions (and a current / hub / other room target) on `/admin/live-events`. Unavailable catalog rows persist without applying a World Effect. Built-in `nimiqlive.test` → Live Boost remains the fallback when that type has no enabled rule.

**Why:** Incoming types will grow (Twitch subscribe and later rewards) faster than World Effects ship. If mapping stayed hardcoded, every new type would need a code change, or NimiqLIVE would start choosing in-game consequences. Room targeting belongs in the same operator table so room-scoped effects can honor it later without a second config surface.

**How it serves the larger system:** Gameplay authority stays on the server. The Live Event envelope stays a notification. Operators own the mapping table (SQLite, same store as accepted ids). Reserved interactions can be assigned now without pretending gold blocks (or other spectacles) already exist.
