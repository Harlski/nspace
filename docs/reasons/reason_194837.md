# Why THE-LARGER-SYSTEM was updated

Opening `/analytics` was stalling live play because Event Log JSONL scans ran on the same Node event loop as the game tick. Recording the isolation rule (Analytics Service sidecar, no in-process fallback, database deferred) keeps that boundary visible the next time someone is tempted to “just scan the logs here.”

This supports a coherent live service: gameplay authority and the tick stay responsive; analytics remains a read of the Event Log, not a second owner of world state.
