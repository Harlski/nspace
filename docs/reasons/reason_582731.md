# Reason 582731

**Date:** 2026-11-22

**Why `THE-LARGER-SYSTEM` changed:** Login history on a player dossier came back empty for a wallet the hourly digest had just ranked. The event log still stores the spaced user-friendly address from the session, and the dossier asked with the compact profile key. Those are the same wallet, and the scan was treating them as two.

**How this serves the larger system:** Profiles, sanctions, and the username gate already use one compact key. Event Log scans now use that same key, so a Telegram row and the dossier describe one player. Future scans should keep that key instead of comparing the raw session string.
