# reason_619472 - Return Gold only on cubes a player can stand beside

## Why THE-LARGER-SYSTEM changed

Vicinity random Upgrades could convert interior solids in a dense cluster. Those cubes have no
orthogonal walkable edge, so the Gold Block claim protocol cannot start (stand beside the block,
edge not diagonal). Recording the stand-tile rule keeps Return Gold on cubes players can actually
reach and click.

## How it serves the larger system

- Same claim geometry as Gold Blocks: authority stays on the play socket, no new click path.
- Convert, do not spawn: the pool is still existing ordinary solids, minus boxed-in tiles that
  would look like gold but could never pay.
- Uniform random among remaining vicinity tiles still lets Return Gold jump away from Resident
  without picking unreachable interiors.
