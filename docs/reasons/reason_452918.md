# reason_452918 — Tutorial Unlock via free message sign

**Why update THE-LARGER-SYSTEM:** First-contact Unlock previously required a real NIM send
(Nimiq Pay / Hub checkout). That conflicted with zero balance and with Nimiq Pay deposit
settlement after the tutorial faucet, stranding learners on the Unlock Pad for a minute or
more. The larger-system note records that tutorial Unlock is intentionally a **free message
sign** plus optimistic door-sent ack, while non-tutorial Unlock Pads remain paid.

**How it serves the larger system:** Keeps the tutorial’s wallet UX lesson (sign / unlock
affordance) without coupling progress to payout latency or spendable balance. Preserves the
split between optimistic tutorial proof and Payment Intent elsewhere (ADRs 0005 / 0007).
