# reason_647281 - Prepaid Return Budget vs Stream Faucet

## Why THE-LARGER-SYSTEM changed

Return Walk is a long-lived Resident loop (Invoice, Deposit, Quiet-Claim, Upgrade Windows,
Return Gold) that must not borrow the Stream Faucet signer or admin HTTP. Recording it as a
cross-cutting decision keeps future work from mixing prepaid Return Budget into mining payouts,
adding a Resident Upgrade POST, or treating cinema `?stream=1` as the Resident seam.

## How it serves the larger system

- Separates **prepaid Return Budget** (Deposit to the Server Wallet) from **gameplay faucet**
  rewards so Daily Earn, mining backlog, and bulk flush cannot spend Resident Deposits.
- Keeps world authority on the play socket: Upgrade Windows use Resident pose at fire time,
  the same intent-in / snapshot-out contract as Gold Blocks.
- Privileged HTTP uses the existing player JWT allowlist (`RESIDENT_ADDRESSES`), not a new
  admin surface, so operators do not grow `/api/admin/*` for a single-wallet bot.
