# reason_361849 - Resident allowlist on `/admin/connections`

## Why THE-LARGER-SYSTEM changed

Return Walk still uses the player JWT for Invoice and directory HTTP (`/api/resident/*`).
Operators also need a live way to set who is Resident without a process restart or a
compose env edit. Recording `/admin/connections` as the allowlist editor (env merged
with runtime JSON, same pattern as stream observers) keeps that ops surface distinct
from gameplay admin APIs.

## How it serves the larger system

- Gameplay authority stays on the play socket and `/api/resident/*`; admins do not
  Invoice, credit Deposits, or pick Upgrade tiles over `/api/admin/*`.
- A dedicated Connections page avoids overloading `/admin/settings` (Shop, tutorial,
  usernames) with a privileged-wallet editor.
- Reusing `admin-runtime-settings.json` avoids a new JSON silo for a small allowlist.
- Fail-closed remains: empty env and empty runtime means no Invoice access.
