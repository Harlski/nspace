# Why THE-LARGER-SYSTEM was updated (619473)

**What changed:** Recorded that NimiqLIVE emits **Live Events** and Nimiq Space maps them to **World Effects**. Ingest is `POST /api/live-events` trusted by the NimiqLIVE Wallet JWT allowlist; **Live Event Id** is the idempotency key so retries do not stack effects.

**Why:** NimiqLIVE already decides that something happened (including operator-fired `nimiqlive.test`). If it also chose rooms, durations, or gold counts, stream tooling would own world rules that belong on the game server. A shared Bearer secret would be a second trust model beside wallet login. Whole-file JSON of accepted ids would grow with every stream event.

**How it serves the larger system:** Room authority stays on the server (`rooms.ts`). The Live Event envelope can grow new types without a new route. Persistence is a bounded SQLite table (indexed id, restore-after-restart) instead of another JSON silo. Players and cinema observers see one reversible Live Boost instead of stacked or client-predicted rewards.
