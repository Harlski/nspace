# Reason 739284

**Date:** 2026-11-22

**Why `THE-LARGER-SYSTEM` changed:** The hourly Telegram digest answers who played and how much gameplay NIM they earned, and it does not show whether that time was one long visit or a string of short ones. Operators were opening `/admin/user/:profile` to look at a single wallet and still could not see the gaps. That per-player read is another Event Log scan, so it belongs with the other scans.

**How this serves the larger system:** Keeping the scan on the Analytics Service leaves the game tick alone and gives the dossier the same connected-versus-active rule the digest already uses. The page defaults to the rolling last 24 hours so the chart and the Telegram table describe the same window. If the sidecar is down, the chart says so and the rest of the dossier still loads. There is no second scan on the game process.
