# Tag Countdown does not freeze Participants

A Tag Round needs a shared “get ready” beat after Start so the Mosquito is not assigned mid-step. Freezing Participants for that beat made the Hub feel like a Match Kickoff, which Mosquito Tag is not. Players asked to keep walking while the rules overlay counts down.

**Decision:** Tag Countdown is **7 seconds**. Participants **can walk**. The overlay shows the rules (don’t get the Mosquito; last Holder loses). Bystanders were never frozen.

**Considered options:** Keep the 3s freeze (rejected: feels like soccer Kickoff). Freeze only the soon-to-be Holder (rejected: Holder is not known yet). Skip countdown entirely (rejected: the rules copy needs a beat).
