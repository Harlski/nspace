# At most one Tag Call or Tag Round per room

Soccer allows several Challenges in one room because each accept pairs two players onto their own Match Pitch. Mosquito Tag has no isolation: Participants and Bystanders share the same floor, Participant Markers, Mosquito, and Boost Pads.

Two concurrent Tag Rounds would make “who is in which hunt” unreadable and would let two Mosquitoes pass through the same crowd. v1 is one open Tag Call or one live Tag Round per room; a second Caller cannot raise while that slot is taken. Other players Join the existing Tag Call rather than starting their own.

Easy to relax later if a huge Commons ever needs parallel hunts; expensive to debug if we ship overlapping mosquitoes first.
