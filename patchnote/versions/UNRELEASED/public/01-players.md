# Public patch notes — players (`UNRELEASED`)

**Audience:** people who play or explore Nimiq Space — features, fixes, and feel; not implementation detail.  
**Depth:** short bullets or short paragraphs; avoid file paths and internal names unless they help (e.g. a renamed control).

---

- On the Main Menu (browser / desktop), choose **Sign in with QR**. Inside Nimiq Pay that button stays hidden; use the normal wallet sign-in there.
- Pick **Nimiq Pay** or **Nimiq Wallet**, then scan the code. The sign-in address is shown under the code with a copy button. Pay opens the confirm flow inside Nimiq Pay; if Pay will not open a link that includes a port, paste that address into the phone browser. Wallet opens the sign-in page so you can confirm with Nimiq Wallet. After you sign, the phone stays on a confirmation that shows the account that authorized the computer (address and Nimiq Pay or Nimiq Wallet). That screen remains if Pay or the browser reloads the page. Return to the computer and it should enter the space automatically.
- Useful on shared or untrusted PCs (for example an internet cafe): the computer never asks for your wallet password.
