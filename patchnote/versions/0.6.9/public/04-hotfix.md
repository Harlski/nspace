# Public patch notes — hotfix (`0.6.9`)

**Audience:** anyone during a corrective release — what broke, what we patched, why now.  
**Depth:** short incident-shaped summary; not a full reasons dump.

---

**What was wrong:** After the Nimiq Pay tutorial lesson, chat stayed muted in the Hub until you changed rooms again. Players thought chat was broken.

**What we changed:**
- [FIX] Lesson chat suppression is limited to Tutorial Room; leaving restores Hub chat immediately.
- [CHANGE] Chat UI is hidden for the lesson itself; tutorial/staging rooms no longer get wandering NPC bots.

**Why now:** Blocks first-contact trust right after onboarding. Small, safe client + server patch.
